# 使用指南

澜流 0.4 起是独立 VPN，支持 Android 10 及以上。升级会保留加速地址和连接上限。Android 通常每个用户只能运行一个 VPN，请先停止同一用户下的其他 VPN。

## 开启播放

1. 安装 BubbleUPnP 和澜流，使用 Wi-Fi 或蜂窝数据。
2. 打开澜流「设置 → 加速链接」。填写支持 HTTP Range 的源地址或域名，每行一个。默认目标为 `lgf.audio.tidal.com`。
3. 点击「开启」，接受 Android VPN 授权。应用显示「等待播放」时可以在 BubbleUPnP 开始播放。
4. 点击澜流「停止」可关闭 VPN，BubbleUPnP 的后续请求恢复为系统直连。

地址设置保存域名和端口，最多 16 项。连接上限默认 8 路，范围为 1–16 路，调低时允许已有请求完成。手机使用蜂窝网络时会消耗移动流量。

## 加速范围

Android 按 IP 路由，仅将 BubbleUPnP 到目标解析 IP 的流量交给 VPN。澜流进一步按 HTTP Host 和端口匹配加速目标，只处理中继所需的 GET 和 HEAD。共享 IP 的其他 TCP 流量原样直连，HTTPS 始终保持加密。同一 IP 上的 UDP（包括 QUIC）不受当前 VPN 支持。其他应用和未路由到 VPN 的地址仍走系统网络。

HTTP 源须支持 Range。依赖额外 Cookie 或 Authorization 请求头的取流暂不支持。使用外部渲染器时，由渲染器直接发出的请求不经过手机 VPN。若更改目标或目标 CDN 地址变化，重建路由可能短暂中断已有连接，播放器可通过新请求继续取流。

## 后台和排障

澜流使用前台 VPN 服务和 Android 默认电池管理。取流时持有 CPU 唤醒锁，请求都完成后约 8 秒释放。同一会话下网络切换后，新取流使用当前可用网络。手机厂商的额外后台限制也可能影响前台 VPN，实际功耗与温度受信号和音质影响。

| 现象 | 检查 |
| --- | --- |
| 正在连接 VPN | 检查 BubbleUPnP 是否安装、VPN 是否授权、配置的域名能否解析，并等待 Wi-Fi 或蜂窝网络可用 |
| 播放正常，澜流没有取流记录 | 检查是否使用 BubbleUPnP 本机播放器，以及实际音源的协议、域名和端口。TIDAL 在不同网络或音质下可能使用不同地址 |
| 锁屏中断 | 在「记录 → 导出诊断」查看 `vpn_running`、`network.blocked`、`background_restricted`、服务进程 ID 和事件 |

诊断记录音源域名、设备信息和运行计数。汇报问题时请附上问题时间、手机型号、系统版本、网络和播放音质。候选版与历史验证范围见 [后台测试](background-testing.md)。
